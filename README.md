# Court Merge — downloads

**[courtmerge.ronagold.be](https://courtmerge.ronagold.be)**

## Nederlands

Deze repository draagt **enkel de downloadbare versies** van Court Merge. Er staat geen
broncode in en die is niet publiek.

Elke stabiele versie staat onder [Releases](https://github.com/judochampion/courtmerge-releases/releases),
met twee bestanden:

- `CourtMerge-Setup-<versie>.exe` — de installer;
- `CourtMerge-<versie>-win-x64.zip` — dezelfde toepassing zonder installatie, voor wie
  geen beheerdersrechten heeft.

Court Merge is een **Windows-desktoptoepassing**. Ze draait niet op macOS, Linux, een
telefoon of een tablet.

Ga voor de huidige versie, de systeemvereisten en de uitleg bij de Windows-waarschuwing
naar **[courtmerge.ronagold.be](https://courtmerge.ronagold.be)**. Vragen en
ondersteuning lopen ook via die site — de issues staan hier uit.

## English

This repository carries **only the downloadable builds** of Court Merge. It contains no
source code, and the source is not public.

Every stable version is published under
[Releases](https://github.com/judochampion/courtmerge-releases/releases), with two files:

- `CourtMerge-Setup-<version>.exe` — the installer;
- `CourtMerge-<version>-win-x64.zip` — the same application without installing, for those
  without administrator rights.

Court Merge is a **Windows desktop application**. It does not run on macOS, Linux, a
phone or a tablet.

For the current version, the system requirements and an explanation of the Windows
warning, go to **[courtmerge.ronagold.be](https://courtmerge.ronagold.be)**. Questions and
support go through that site as well — issues are disabled here.
